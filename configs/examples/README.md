# Восстановленные примеры конфигурации

Эти XML-фрагменты созданы для документации по краткому описанию. Они **не экспортированы из исходного стенда**, не проверялись работающим Wazuh Agent и не являются полными `ossec.conf`.

| Файл | Назначение |
|---|---|
| [client.fragment.xml](client.fragment.xml) | Пример адреса Manager для агента |
| [auth-localfile.fragment.xml](auth-localfile.fragment.xml) | Чтение auth.log при наличии и доступности файла |
| [fim-syscheck.fragment.xml](fim-syscheck.fragment.xml) | Пример наблюдения за тестовым каталогом |

Перед использованием посмотреть существующий `/var/ossec/etc/ossec.conf`: источники могут быть уже настроены. `client` и `syscheck` следует объединять с существующими секциями. Добавление второй секции вместо корректного изменения действующей может привести к нежелательному поведению. Весь конфиг этими фрагментами не заменять.

`WAZUH_SERVER_IP` — заполнитель, его требуется заменить. В примерах нет ключей регистрации, паролей, сертификатов и правила firewall. Включение `realtime="yes"` в примере — документированный вариант теста, а не доказательство того, что именно этот параметр стоял у автора.

Проверка XML-парсером подтверждает только синтаксическую корректность. Совместимость с выбранной версией Wazuh и фактическая доставка событий проверяются отдельно.
