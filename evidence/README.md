# Реестр доказательств

[manifest.csv](manifest.csv) связывает заявления о проекте с проверками и артефактами. Сейчас артефакты не предоставлены: пустые поля не означают нулевой уровень или успешный тест.

- `id`: идентификатор записи портфолио E01–E11, не ID правила Wazuh.
- `claim`: что требуется подтвердить.
- `source_status`: что сообщил автор.
- `artifact_status`: доступность подтверждения в этом репозитории.
- `artifact_path`: относительный путь от корня репозитория к обезличенному файлу.
- `rule_id`, `level`, `observed_at`: только фактические значения; для неприменимых полей оставить пусто.

Для временных меток желательно использовать ISO 8601 с часовым поясом. Не угадывать время событий по дате создания README. Не копировать сюда содержимое секретных файлов и полный экспорт данных без проверки.
