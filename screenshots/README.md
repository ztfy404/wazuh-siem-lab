# Скриншоты проекта

В исходном описании упомянут архив из 14 изображений, но изображения ещё не предоставлены. Этот каталог не содержит поддельных снимков Dashboard.

Рекомендуемый набор реальных подтверждений:

| ID | Предлагаемое имя | Что должно быть видно |
|---|---|---|
| E02 | 01-services.png | Статусы серверных служб |
| E03 | 02-filebeat-output.png | Успешная проверка Filebeat без секретов |
| E04 | 03-dashboard.png | Рабочий интерфейс |
| E05 | 04-agent.png | Подключённый Astra Linux агент |
| E06 | 05-ssh-event.png | SSH-событие, агент и время |
| E07 | 06-sudo-event.png | Событие sudo и контекст |
| E08 | 07-fim-created.png | Создание файла, если алерт получен |
| E09 | 08-fim-modified.png | Изменение файла, если алерт получен |
| E10 | 09-fim-deleted.png | Удаление файла, если алерт получен |
| E11 | 10-package-versions.png | Установленные версии |

Это план имён, файлы с такими именами пока отсутствуют. Один снимок может подтверждать несколько записей; снимки без доказательной пользы добавлять ради количества не требуется.

Убрать пароли, ключи, персональные имена/email и внутренние адреса при необходимости. Обезличивание делать последовательно и отмечать замену адресов; названия правил, уровень, тип события и временную последовательность сохранять, чтобы результат можно было понять. Оригиналы с секретами хранить вне Git.

После добавления заполнить `artifact_path`, `rule_id`, `level`, `observed_at` в [manifest.csv](../evidence/manifest.csv) и добавить изображения в README по относительным путям.
