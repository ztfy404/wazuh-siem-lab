## Краткое описание от первого лица

Развернул учебный SIEM-стенд Wazuh в Oracle VirtualBox: сервер All-in-One на Ubuntu Server и агент на Astra Linux. Подключил Linux-узел к централизованному мониторингу, проверил события SSH и sudo, настроил тестовый каталог контроля целостности и выполнил операции с файлами. Описал архитектуру, диагностику и порядок контрольных проверок.

Текст опирается на описание автора. Перед использованием сверить с фактически выполненными действиями; не добавлять неподтверждённые результаты.

## Пункты для резюме

- Развернул Wazuh Manager, Indexer и Dashboard на Ubuntu Server в локальной виртуальной инфраструктуре.
- Установил и зарегистрировал Wazuh Agent на Astra Linux, проверил отображение источника в Dashboard.
- Выполнил проверки мониторинга SSH, sudo и файловых изменений в тестовом каталоге.
- Проверил соединение Filebeat с Indexer и диагностировал проблемы запуска компонентов и сетевой доступности.
- Подготовил документацию архитектуры, подключения агента и контрольных сценариев.
