# Wazuh Agent на Astra Linux

## Что известно

На Astra Linux Orel 2.12.46 x86_64 установлен и зарегистрирован Wazuh Agent 4.14.10 по описанию автора. Агент отображался в Dashboard. Пакет, точная команда установки, имя и ID агента не предоставлены. Поддержка и зависимости на Astra Linux при новом развёртывании проверяются отдельно; считать любую Debian-совместимую ОС автоматически поддерживаемой нельзя.

## Порядок подключения

1. Определить реальный адрес Manager, доступный из Astra Linux.
2. Получить подходящий пакет и команды для выбранной версии через раздел добавления агента в Dashboard и [официальную документацию агента](https://documentation.wazuh.com/current/installation-guide/wazuh-agent/index.html).
3. Установить пакет, настроить адрес Manager и выполнить регистрацию выбранным способом. Исходный способ регистрации и его параметры не сохранены.
4. Проверить активность службы, наличие агента в Dashboard и получение конкретного тестового события.

Не публиковать `client.keys`, enrollment-пароли и автоматически сформированные команды с секретами.

## Проверка установленного агента

На Astra Linux:

```bash
systemctl is-active wazuh-agent
dpkg-query -W -f='${binary:Package}\t${Version}\n' wazuh-agent
```

При необходимости локально проверить `/var/ossec/logs/ossec.log`; этот журнал в репозитории не приложен. Активная служба ещё не подтверждает соединение с Manager — сверить Dashboard и тестовые события.

## Источники

- `/var/log/auth.log`: в описании использовался для SSH и sudo.
- `/opt/siem-fim-test/`: тестовый каталог FIM.

Сначала проверить наличие источников в установленной ОС и действующий `ossec.conf`, чтобы не добавлять дублирующиеся `localfile` или `syscheck` секции. Примеры находятся в [configs/examples](../configs/examples/README.md); это восстановленные фрагменты, не исходная конфигурация автора.

При изменении настроек:

1. Сделать локальную копию конфигурации вне репозитория.
2. Внести только нужные изменения в существующие секции `/var/ossec/etc/ossec.conf`.
3. Проверить конфигурацию средствами установленной версии Wazuh.
4. Перезапустить службу и подтвердить её запуск:

```bash
sudo systemctl restart wazuh-agent
systemctl is-active wazuh-agent
```

При ошибке восстановить локальную копию и проверить журнал агента. Изменение конфигурации, её синтаксическая проверка и фактическая доставка событий — разные этапы.
