# Проверка подготовленного репозитория

При подготовке выполнены статические проверки относительных ссылок Markdown, синтаксиса XML-фрагментов, синтаксиса Bash и структуры CSV. Проверены вывод справки диагностического скрипта и отказ при неизвестной роли. Архив проверен на целостность.

Эти проверки относятся к документации и добавленному инструменту. Они не являются проверкой исходного стенда Wazuh, поддерживаемости ОС, подключения агента или срабатывания алертов. ВМ автора не запускались. Статические проверки содержания не подтверждают работоспособность стенда и не заменяют проверку доступа к опубликованному репозиторию.
