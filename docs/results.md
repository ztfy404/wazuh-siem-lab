# Результаты

Я развернул Wazuh All-in-One на Ubuntu Server и подключил агент на Astra Linux.

| Что проверял | Результат |
|---|---|
| Серверные компоненты | Manager, Indexer, Filebeat и Dashboard запустились |
| Filebeat → Indexer | Проверка соединения и TLS handshake прошла |
| Dashboard | Интерфейс открылся в браузере |
| Агент | Зарегистрирован и виден в Dashboard |
| SSH | События нашёл в журнале Linux и Threat Hunting |
| sudo | Проверил регистрацию событий |
| FIM | Настроил тестовый каталог и выполнял создание, изменение и удаление файла |

Скриншоты добавлю позже. Для FIM отдельно покажу, какие события появились после каждой операции; точные ID правил пока не записываю.

Для меня главный результат — я разобрался, как подключить Linux-машину к SIEM и проследить путь события от локального журнала до интерфейса Wazuh.

Это локальный учебный стенд с одним агентом. Собственные правила и декодеры я в этом проекте не описываю.
