# Источник и границы достоверности

## Переданные материалы

Один текстовый документ «Проект: развёртывание SIEM Wazuh в виртуальной инфраструктуре», подготовленный по другой переписке автора. Он содержит разделы о цели, архитектуре и текущем состоянии, ссылается на прежний отчёт и архив из 14 скриншотов. Сам отчёт, архив, исходные конфигурации и история команд здесь не предоставлены.

Поэтому сведения о выполненных действиях — **сообщённые автором результаты**. При подготовке репозитория нет доступа к его ВМ, Dashboard или прежнему чату. Здесь не выполнено независимое подтверждение алертов и работы служб.

## Происхождение файлов

| Материал | Происхождение |
|---|---|
| README, архитектура и результаты | Оформлены по предоставленному описанию |
| Развёртывание и диагностика | Восстановленный порядок; не исходный журнал команд |
| XML в configs/examples | Новые иллюстративные примеры |
| scripts/collect-health.sh | Новый вспомогательный диагностический скрипт |
| Сценарии тестов | Описание сообщённых действий плюс новые команды для повторения |
| evidence/manifest.csv | Реестр ожидаемых подтверждений; не результаты новых тестов |

## Неизвестные значения

Версия VirtualBox/Filebeat, точная модель CPU, итоговые ресурсы одновременно работающих ВМ, ID/имя агента, реальные IP, точные rule ID и уровни, параметры установщика, исходный `ossec.conf`, точные ошибки и команды исправления не предоставлены.

Не следует подменять эти значения «типовыми». Штатные правила Wazuh не приписываются автору как его собственная разработка. Без отдельного подтверждения проект не описывается как production, отказоустойчивый кластер или система с автоматическим реагированием.
