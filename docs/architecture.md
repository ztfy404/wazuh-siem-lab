# Как устроен мой стенд

Я использовал две виртуальные машины в VirtualBox на компьютере с Windows 10.

| Машина | ОС | Роль |
|---|---|---|
| Сервер | Ubuntu Server 24.04 LTS | Wazuh Manager, Indexer, Dashboard и Filebeat |
| Агент | Astra Linux Orel 2.12.46 | Wazuh Agent и тестовые события |

Версия Wazuh — 4.14.10. Windows я использовал только как хост, агент на неё не ставил. Docker для Wazuh не использовал.

## Ресурсы

У моего компьютера 16 ГБ оперативной памяти. Серверной ВМ я выделил 4 vCPU и около 8 ГиБ RAM. Диск сначала был примерно 25 ГиБ, потом я расширил его примерно до 85 ГБ.

Ресурсы второй ВМ менялись во время работы, поэтому точную итоговую конфигурацию здесь не указываю. При повторении нужно оставить память и для Windows, а не отдавать её всю виртуальным машинам.

## Сеть

В итоге я выбрал **Bridged Adapter**, то есть сетевой мост. Виртуальные машины получали адреса в локальной сети. В примерах вместо своих адресов использую `WAZUH_SERVER_IP` и `ASTRA_AGENT_IP`.

| Порт | Для чего |
|---|---|
| TCP 1514 | Агент передаёт события Manager |
| TCP 1515 | Регистрация агента |
| TCP 443 | Доступ к Dashboard через браузер |
| TCP 22 обычно | Подключение по SSH |
| TCP 9200 обычно | Filebeat подключается к Indexer |

Последние два порта нужно сверять с действующими настройками. Indexer находится на той же ВМ, что и остальные серверные компоненты; открывать его всей сети для этого стенда не нужно.

## Путь события

Агент собирает данные на Astra Linux и отправляет их в Manager. После обработки Filebeat передаёт данные в Indexer. В Dashboard я ищу и просматриваю эти события.
